# Usage Rail Phone

同一排圆环，放进口袋。点一下，明细才摊开。它不自己去登录。把 Mac 上写下的 `usage.json` 带过来，或者填一个返回同样内容的地址。

The same rings, pocket-sized. Tap one, and the card opens.

| Ring | What it draws |
|---|---|
| GPT | Outer 5-hour, inner week |
| Claude | Outer 5-hour, inner week |
| Grok | Week |
| Kimi | Outer month, inner 5-hour |
| DeepSeek | Account balance |

Open `UsageRail.xcodeproj`.

桌面那条粉缝在 [`mac`](../mac)。要哪边拿哪边。
